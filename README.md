# Siemens EDA — Formal Verification Diploma

**RTL Design · Digital Logic · Hardware Verification Fundamentals**

This repository collects coursework, exercises, and supporting materials from my **Siemens EDA Formal Verification Diploma (February–April 2023)**. The training strengthened my foundation in digital hardware design and introduced the concepts and development practices used in hardware verification.

My hands-on work included designing **sequential logic components in Verilog**, such as flip-flops and registers, and implementing a **FIFO (First-In, First-Out) memory**. The diploma also covered VHDL and supporting engineering workflows involving Linux shell scripting, Makefiles, and Python.

## Technical Focus

| Area | Topics and experience |
| --- | --- |
| **RTL design** | Verilog HDL; sequential logic, flip-flops, and registers |
| **Digital design** | FIFO memory and associated read/write behavior |
| **Hardware description languages** | Verilog design work and VHDL fundamentals |
| **Development workflow** | Linux command-line tools, shell scripting, Makefiles, and Python |
| **Verification foundations** | Formal verification training and hardware correctness concepts |

## Selected Hands-On Work

### Sequential Logic in Verilog

Designed flip-flops and registers to practice modeling clocked hardware, state changes, and sequential behavior at RTL level.

### FIFO Memory Design

Built a FIFO memory design in Verilog to explore buffering, read/write operations, and state management in a digital system.

The work shown here is educational coursework focused on digital design and verification fundamentals.
